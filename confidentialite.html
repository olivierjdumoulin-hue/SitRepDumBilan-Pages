Politique de confidentialité

Application : SitRepDumBilan

1. Objet

SitRepDumBilan est un outil personnel de consultation et de synthèse d'informations d'organisation quotidienne.

2. Données accessibles

Selon les autorisations accordées, l'application peut traiter :

  • Les événements Google Agenda.
  • Les contacts Google et leurs anniversaires.
  • Les tâches TickTick.
  • Les informations nécessaires à l'envoi de messages via Gmail.

3. Finalités

Ces données servent à produire un tableau de bord personnel, afficher les tâches, les événements et les anniversaires, et permettre l'envoi de messages autorisés.

4. Stockage et sécurité

L'application utilise des autorisations OAuth. Les données peuvent être traitées et conservées localement sur les appareils de l'utilisateur pour assurer le fonctionnement du tableau de bord.

Les jetons d'authentification ne doivent pas être publiés dans un dépôt public.

5. Partage des données

SitRepDumBilan n'a pas vocation à vendre les données personnelles ni à les utiliser à des fins publicitaires. Les données ne sont pas destinées à être partagées avec des tiers, sauf lorsque l'utilisateur déclenche une fonctionnalité impliquant un service externe.

6. Contrôle des autorisations

L'utilisateur peut retirer les accès Google depuis les paramètres de sécurité de son compte Google.
